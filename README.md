Design

This folder contains the system design and modelling artefacts developed for the Software Engineering project.
The diagrams in this folder are used to represent the system from different perspectives, including its functional requirements, workflows, interactions, and structural design.

## Diagrams Included
1. Use Case Diagram
The Use Case Diagram illustrates the main actors involved in the proposed system and the interactions between the actors and the system. It provides an overview of the major functionalities and system requirements.
2. Manual System Activity Diagram
The Manual System Activity Diagram represents the workflow of the existing manual system. It shows the sequence of activities involved in the current process and helps identify the limitations and areas that can be improved.
3. Proposed System Activity Diagram
The Proposed System Activity Diagram illustrates the workflow of the proposed system. It demonstrates how the activities are expected to be performed after introducing the proposed solution and highlights improvements over the existing manual process.
4. Sequence Diagram
The Sequence Diagram represents the interaction between the actors and system components over time. It shows how messages are exchanged between different elements of the system to complete specific processes.
5. Class Diagram
The Class Diagram represents the structural design of the proposed system. It identifies the major classes, their attributes and methods, and the relationships between the classes.

## Purpose
These design artefacts provide a visual representation of the proposed system and support the analysis, design, and documentation phases of the Software Engineering project.
